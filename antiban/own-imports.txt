# Win32 functions that Mapper's own object file (mapper_lib, built without LTO by
# `npm run guard:obj`) may import. Any other name fails the guard: a new Win32 call in Mapper's
# code needs a line here, with its reason, in the same PR. Names on the guard's forbidden list
# never pass, whatever this file says, and an entry that is no longer imported must be removed.
#
# "ours" lines name the file in src-tauri/src/platform/win that makes the call. "dependency"
# lines come from generic code of tao, wry, muda, tray-icon, webview2-com or std that Rust
# instantiates inside mapper_lib; every one of them acts on Mapper's own windows and threads.
#
# Audited on mapper_lib 0.1.0 (Phase 4, 2026-10-28): 56 Win32 imports.
