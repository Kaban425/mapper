## Цель

Лёгкое Windows-приложение: игрок открывает карту в PUBG, жмёт горячую клавишу, ставит
две (или больше) точки, а приложение показывает расстояние, значение для прицела миномёта
и примерное время в пути. Приложение выкладывается на GitHub с открытым кодом, должно
выглядеть качественно и современно и **не должно быть читом**.

## Жёсткие ограничения (анти-бан)

PUBG Dev Letter от 2026-06-25 (https://pubg.com/en/news/10338) наказывает сторонние
программы, которые: показывают информацию, которой нет в игре; меняют UI игры без
разрешения; обращаются к клиенту или процессам игры, чтобы собирать данные. Поэтому:

1. **Отдельный процесс и отдельное окно.** Никаких инжектов, DLL, хуков DirectX/Vulkan,
   отрисовки внутри игры.
2. **Не читаем память, файлы и процессы игры.** Не ищем окно игры ни по процессу, ни по
   заголовку. Mapper не знает, запущена ли игра.
3. **Не читаем и не анализируем экран.** Никаких скриншотов, OCR, компьютерного зрения.
   Все точки и калибровку ставит человек кликами.
4. **Не отправляем ввод в игру.** Никаких макросов, эмуляции клавиш и мыши, автоприцела.
   В том числе не вызываем `set_focus()` из tao/Tauri: при неудаче он эмулирует Alt через `SendInput`.
5. **Mapper считает только по точкам, которые игрок отметил сам, и по публичным константам**
   (сетка, FOV из настроек, параметры миномёта). Ничего не определяется автоматически и ничего
   не появляется без действия игрока.
6. **Горячие клавиши только через `RegisterHotKey`.** Без хуков, raw input и `GetAsyncKeyState`
   (своя обёртка, без `tauri-plugin-global-shortcut`).
7. **Честный README.** 100% гарантии от бана нет ни у одной сторонней программы. Описать, что
   приложение делает и чего не делает. Без слов safe, undetected, undetectable.
8. **Без прав администратора** (`asInvoker`). Если игра запущена от администратора, это только
   описывается в документации.
9. **Не прячемся.** Постоянные заголовки и классы окон, version resource, без упаковщиков (UPX)
   и обфускации, релизы собираются только в CI с attestations.

## Принятие риска

Автор принял формулировку 2026-10-20. Риск обнаружения низкий: Mapper не трогает процесс,
память, экран и ввод игры. Риск по правилам ненулевой: Rules of Conduct запрещают
неразрешённые программы, которые «promote unfair game play», белого списка нет. Тесты в игре
идут на аккаунте автора, по минимуму, в Training Mode и только релизной сборкой.

## Решения автора

| Вопрос | Решение |
|---|---|
| Режим работы | Прозрачный оверлей поверх игры, точки ставятся ручными кликами. Вне замера оверлей скрыт |
| Режим экрана в игре | Без рамки (Borderless). Эксклюзивный полноэкранный не поддерживаем |
| Стек | Tauri 2.12 (Rust + Svelte 5 + TypeScript), WebView2 |
| Масштаб карты | **Универсальная линейка по крайним зумам.** Игрок прокручивает зум карты до упора: максимальное приближение для близких дистанций (до ~600 м), максимальное отдаление для дальних. Масштаб для каждого из двух зумов настраивается один раз (совмещение сетки: 100 м на приближении, 1 км на отдалении) и хранится по разрешению монитора. Он одинаков на всех картах 8×8, поэтому выбора карты нет. Промежуточный зум в v1.0 не поддерживается |
| Управление | **Alt+Q** — замер при максимальном приближении, **Alt+W** — при максимальном отдалении (у каждого хоткея свой масштаб, перепутать режим нельзя). ЛКМ ставит точку, ПКМ убирает последнюю, колёсико ±1 м высоты, Shift+колёсико ±10 м, Esc или тот же хоткей выходит. Клавиши переназначаются. В PUBG Alt+Q не оставляет залипший свободный обзор (проверено) |
| Карты | Только рейтинг: Erangel, Miramar, Taego, Rondo — все 8×8 км. Линейка работает на любой карте 8×8; Sanhok, Paramo, Karakin в v1.0 не поддерживаются |
| Монитор | Оверлей открывается на мониторе под курсором в момент нажатия клавиши; можно закрепить монитор в настройках |
| Высота для миномёта | v1.0: ручная докрутка колёсиком. v1.1: клик по цели в 3D-виде (угломер) как экспериментальная функция, по умолчанию выключена |
| Время в пути | По линии маршрута: бег (спринт) и Dacia без ускорения (без Shift). Скорость Dacia замерить в игре |
| Дизайн | **«Жидкое стекло» + акцент #F2A900**: полупрозрачные стеклянные панели с бликами и мягкими скруглениями, линия и цифры жёлтые, чтобы читаться на любой карте. Настоящее размытие фона (Windows acrylic) — в маленьких окнах (результат, настройки); панели на самом оверлее стеклянные по виду, без размытия карты под ними |
| Язык | Русский + English (переключатель в приложении, README на двух языках) |
| Сборка | Portable .exe и установщик NSIS (MSI не делаем), оба собирает GitHub Actions в Releases |
| Обновления | Только уведомление о новой версии со ссылкой на Releases. Запрос из Rust, не чаще раза в сутки, с переключателем. Единственный сетевой запрос приложения |
| Название | **Mapper**, подпись «for PUBG: BATTLEGROUNDS». Слово PUBG в названии не используем |

## Функции v1.0

1. **Дистанция между двумя точками.** Линия с засечками, подпись в метрах, рядом «±N м» и
   режим зума («приближено» / «отдалено»).
2. **Маршрут из нескольких точек.** Длина каждого отрезка и общая длина.
3. **Миномёт.** Значение для прицела с поправкой на перепад высот, заданный колёсиком.
   Предупреждение, если цель вне дальности 121–700 м или решения нет. Если проверка G-2
   не пройдёт, поправка на высоту выходит как экспериментальная.
4. **Время в пути.** Бегом и на Dacia без ускорения, со знаком «≈» и указанием скорости.
5. **Универсальная линейка.** Два пресета масштаба (макс. приближение, макс. отдаление) для
   всех карт 8×8, у каждого свой хоткей.
6. **Однократная настройка пресетов.** Мастер первого запуска и пункт в настройках:
   выбрать клетки (1 км / 100 м) → клик на пересечение → клик на соседнее пересечение →
   доводка колесом по дальним линиям → Enter. Хранится по разрешению и масштабу монитора.
7. **Скрытый оверлей вне замера.** Результат после замера показывает маленькое click-through
   окно HUD, оно само скрывается примерно через 10 с.
8. **Главное окно (GUI)** в стиле «жидкое стекло» с настоящим размытием Windows (acrylic/mica):
   - **Мастер первого запуска** (3–4 экрана): как это работает; честно про безопасность и риск;
     режим экрана PUBG «Полноэкранный (в окне)»; настройка обоих масштабов с подсказками
     (что приблизить/отдалить до упора, какие клетки совмещать). Новичок с GitHub должен
     разобраться без README.
   - **Статус и масштабы** (главный экран): готовы ли Alt+Q / Alt+W (масштаб настроен, для
     какого монитора и разрешения, сколько метров видно на экране), кнопки «перенастроить» и
     «сбросить», последний замер (только текущий, без истории), статус хоткеев (заняты ли).
   - **Настройки:** хоткеи (запись нажатием, проверка занятости), язык RU/EN, скорости
     (спринт, Dacia без ускорения — значение по умолчанию помечено «не проверено»),
     прозрачность панелей, монитор (под курсором / закреплённый), автозапуск с Windows,
     проверка обновлений (вкл/выкл), «о программе» (версия, лицензия, ссылки, отказ от
     связи с KRAFTON, что программа делает и не делает).
   - **Запуск:** открывается главное окно; крестик сворачивает в трей, хоткеи продолжают
     работать; выход — из трея или кнопкой в окне. Одна копия приложения (named mutex).
9. **Уведомление о новой версии** через GitHub Releases API. Адрес репозитория — одна
   константа `OWNER/mapper`, автор заменит перед публикацией.

## Нефункциональные требования

- Минимум нагрузки во время игры: простой без перерисовок, CPU 0,0% и окно скрыто, когда
  замер не активен. RAM измерить и записать в README.
- Корректная работа с масштабированием Windows (DPI 100–200%) и разными разрешениями
  (1080p, 1440p, 4K, ultrawide), в том числе с вертикальным монитором.
- Чистый код, тесты математики с покрытием не ниже 80% (масштаб, дистанция, миномёт, время).
- **Anti-ban guard блокирует CI:** запрещённые API, крейты и npm-пакеты, Tauri-права и
  импорты релизного exe сверяются с baseline. Каждое исключение описано в README.
- Красивый README: GIF, таблица «Делает / Не делает», заметная оговорка про риск, раздел
  «Почему это не чит», установка, горячие клавиши, FAQ, SHA256 и инструкция для SmartScreen.
- README: «не использовать в турнирах; в Ranked на усмотрение игрока», «not affiliated with
  KRAFTON». Никаких изображений карт, логотипов и шрифтов игры в репозитории и в exe.
- Лицензия MIT.

## Что осталось проверить

Факты исследования — в `research/RESEARCH.md`, спайки — в `research/SPIKES.md` (S-1 пройден в
игре, Alt+Q не залипает). Универсальная линейка проверена автором в игре (2026-10-20):

- **U-1 — пройдено.** Масштаб при приближении и при отдалении до упора совпал на разных
  картах 8×8 без подгонки.
- **U-2 — пройдено.** При приближении до упора 600 м помещаются на экране.
- **U-3 — нет цифр.** Скорость Dacia без ускорения не замерена: в настройках значение по
  умолчанию с пометкой «не проверено», пользователь может поправить.

До релиза: S-4 (вертикальный монитор), S-2 (вспышки на съёмке), S-3 (PresentMon), G-2/G-3
(миномёт).

## Вне рамок

- **Спавны машин, секретные комнаты, точки лута** — ни поверх игры, ни в отдельном окне.
  Это «информация, которой игра не даёт» из Dev Letter 2026-06-25; автор отказался из-за
  риска бана (2026-10-20).
- Выбор карты (все карты рейтинга 8×8), карты меньше 8×8, промежуточный зум.
- История замеров (показывается только последний замер).
- Эксклюзивный полноэкранный режим, консоли, PUBG Mobile.
- Любое распознавание экрана, чтение данных игры, отправка ввода.
- Второй экран и телефон (можно позже как отдельную функцию).
- Аккаунты, сервер, телеметрия.
