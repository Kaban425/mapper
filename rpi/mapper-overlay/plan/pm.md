# Mapper v1.0 — требования к продукту (PRD)

> RPI, шаг 3 (Plan), 2026-10-20. Основа: `REQUEST.md`, `research/RESEARCH.md`, `research/SPIKES.md`.
> Решения автора не пересматриваются, здесь они сведены в проверяемые требования.

## 1. Продукт, контекст и цель v1.0

**Mapper** («for PUBG: BATTLEGROUNDS») — бесплатная линейка с открытым кодом (MIT) для Windows
10/11. Игрок открывает карту, жмёт `Alt+Q` (карта приближена до упора) или `Alt+W` (отдалена до
упора), кликами ставит точки и получает дистанцию с «± N м», значение прицела миномёта с
поправкой на перепад высот и время в пути бегом и на Dacia. Вне замера оверлей скрыт, результат
~10 с показывает маленький HUD. Карты рейтинга (Erangel, Miramar, Taego, Rondo) — 8×8 км, поэтому
масштаб зависит только от зума: два масштаба настраиваются один раз на монитор, выбора карты нет.

**Почему сейчас.** Dev Letter PUBG от 2026-06-25 наказывает программы, которые показывают
информацию, которой нет в игре, меняют её UI или читают её процессы. Аналоги нарушают хотя бы
одно: захват экрана (PUBG-Overlay), хуки и права администратора (PUBGMortar.NET), ввод в игру
(MortarAid4PUBG). Спайки показали, что оверлей без этого работает: фокус 105/105, ноль утечек
ввода, карта PUBG не реагирует на клики во время замера.

**Цель v1.0:** новичок с GitHub безопасно ставит Mapper, без README настраивает оба масштаба и
делает первый точный замер, а CI доказывает соблюдение C-1…C-9.

## 4. Пользовательские истории

MoSCoW внутри v1.0: **M** — блокирует релиз, **S** — можно выпустить с описанным ограничением,
**C** — если успеваем.

### Первый запуск и масштабы

**US-1 Мастер первого запуска (M).** Как новичок, я хочу пошаговый мастер, чтобы настроить
Mapper без README.
- Given настроек нет, When Mapper запущен, Then открывается мастер из 4 экранов: как это
  работает; риск (текст RESEARCH §8); режим PUBG «Полноэкранный (в окне)»; оба масштаба.
- Экран масштабов говорит, что приблизить или отдалить до упора, что нажать и какие клетки
  совмещать (100 м / 1 км). Калибровка завершена Enter → шаг отмечен без перезапуска.
- Мастер можно закрыть раньше: главный экран покажет «не настроено».

**US-2 Настройка двух масштабов (M).** Как миномётчик, я хочу один раз совместить сетку для
крайних зумов, чтобы мерить на любой карте 8×8.
- На оверлее: клетки (`1` = 1 км, `2` = 100 м, спрашивается всегда) → клик по пересечению →
  клик по соседнему → колесо (Shift — тонко) до совпадения дальних линий → Enter; Esc отменяет.
- Масштаб хранится по зуму и монитору (размер оверлея в CSS px + масштаб Windows).
- Given масштаба нет, When нажат хоткей, Then открывается калибровка.
- 3 клетки дают 300 м (`Alt+Q`) или 3 000 м (`Alt+W`) в пределах «±».

### Замер

**US-3 Замер дистанции (M).** Как миномётчик, я хочу нажать хоткей над картой и кликнуть две
точки, чтобы сразу увидеть дистанцию.
- Оверлей открывается на мониторе под курсором (или закреплённом) и получает фокус; клики,
  колесо и клавиши до игры не доходят.
- ЛКМ — точка, ПКМ — убрать последнюю. Линия и цифры #F2A900, засечки 100 м (при плотных — 1 км).
- Подпись: метры, «± N м» (1,5 px × √2 × √отрезков × м/px + 0,5 px на ширине сравнённых
  клеток), «приближено» / «отдалено».
- Esc или тот же хоткей закрывает только после отпускания всех клавиш (страховка 1 с); фокус
  возвращается прежнему окну.

**US-4 Сетка в замере (S).** Как миномётчик, я хочу видеть и поправлять сетку на месте, чтобы
заметить сбитую калибровку.
- Бледная сетка; `G` прячет, `T` меняет шаг 1 км / 100 м.
- Ctrl+колесо подстраивает масштаб (страница WebView2 не зумится), средняя кнопка переносит
  начало сетки; поправка сохраняется.

**US-5 Маршрут (M).** Как игрок, я хочу ставить больше двух точек, чтобы знать длину пути.
- Видны отрезки и общая длина; «±» растёт как √(число отрезков); 20 точек — без задержки.

**US-6 Миномёт с Δh (M).** Как миномётчик, я хочу задать перепад высот колесом, чтобы получить
прицел с поправкой.
- Колесо ±1 м, Shift ±10 м; Δh видно рядом с результатом.
- R(L, Δh) по PUBGMortar.NET: M = 700 м, t = Δh/L, δ = M² − 2LMt − L², R = (L + t(M − √δ)) /
  (t² + 1); golden-векторы.
- L вне 121–700 м или δ < 0 → «вне дальности» / «нет решения». Только для двух точек (О-4).
- G-2 не пройден → поправка помечена «экспериментально», по умолчанию дальность без высоты.

**US-7 Время в пути (S).** Как игрок, я хочу знать время пути, чтобы решить, успею ли до зоны.
- По длине маршрута: спринт 6,3 м/с и Dacia без ускорения; «≈ 1 мин 35 с» со скоростью.
- Скорость Dacia помечена «не проверено» до замера U-3.

**US-8 Результат в HUD (M).** Как миномётчик, я хочу видеть результат после закрытия оверлея,
чтобы вернуться в бой.
- Замер с ≥ 2 точками закрыт → HUD показывает дистанцию, «±», миномёт, время, зум и скрывается
  через ~10 с; новый замер заменяет старый.
- HUD click-through, `focusable:false`, без команд в ACL.

**US-9 Переключение режима (M).** Как миномётчик, я хочу нажать хоткей другого зума во время
замера, чтобы исправить ошибку без новых кликов.
- Чужой хоткей меняет масштаб, точки остаются, цифры пересчитываются; свой хоткей или Esc
  закрывает. Нет масштаба другого зума → его калибровка.

### Главное окно и настройки

**US-10 Статус и масштабы (M).** Как игрок, я хочу видеть готовность к замеру, чтобы не узнать
о проблеме в бою.
- Для каждого хоткея: настроен ли масштаб, монитор и разрешение, сколько метров на экране
  (приближение ~600 м); хоткей работает или занят.
- Последний замер: один, без истории, на диск не пишется.
- «Перенастроить» объясняет, что нажать над картой; «Сбросить» — после подтверждения.
- Размытие mica/acrylic; на Windows 10 текст читаем на запасном фоне.

**US-11 Хоткеи с записью (M).** Как игрок, я хочу назначить хоткеи нажатием, чтобы выбрать
удобные и свободные.
- Запись — нажатием в фокусе окна Mapper; проверка пробной `RegisterHotKey`, занятая
  отклоняется с сообщением.
- Нельзя: одинаковые хоткеи зумов; клавиши замера без модификатора (Esc, Enter, T, G, 1, 2).
- Подсказка: модификатор игра видит, клавиша без него (F7) в игру не попадает. Действует сразу;
  «по умолчанию» → `Alt+Q` / `Alt+W`.

**US-12 Язык (M).** Как игрок, я хочу RU или EN, чтобы читать на своём языке.
- Меняются главное окно, оверлей и HUD без перезапуска; первый запуск — по языку Windows.

**US-13 Скорости (S).** Как игрок, я хочу поправить скорости под свои замеры.
- Спринт, м/с (6,3, pubg.wiki.gg) и Dacia без ускорения, км/ч («не проверено»); вне диапазона
  отклоняется; есть «по умолчанию».

**US-14 Монитор и прозрачность (S).** Как игрок с двумя мониторами, я хочу выбрать монитор и
прозрачность, чтобы оверлей был над игрой и не закрывал карту.
- «Под курсором» (по умолчанию) или закреплённый; закреплённый отключён → под курсором и
  отметка на главном экране.
- Прозрачность — только у стеклянных панелей; линия, точки и цифры непрозрачны.

**US-15 Автозапуск (C).** Как игрок, я хочу запуск с Windows, чтобы хоткеи работали сразу.
- Запись автозапуска текущего пользователя без прав администратора; окно при старте — О-5.

**US-16 Уведомление о новой версии (S).** Как игрок, я хочу знать о новой версии и уметь это
выключить.
- `GET /repos/OWNER/mapper/releases/latest` из Rust раз в сутки максимум, с ETag; единственный
  сетевой запрос, WebView2 в сеть не ходит; адрес — константа `OWNER/mapper`.
- Новая версия → уведомление со ссылкой на Releases, ничего не скачивается; ошибка сети — только
  в журнал; переключатель выключает запрос.

**US-17 «О программе» (M).** Как новичок, я хочу знать, что программа делает и чего не делает,
чтобы решить, доверять ли ей.
- Версия, MIT, ссылки, «Mapper не связан с KRAFTON»; «Делает / Не делает» как в README, включая
  снимок 256 клавиш tao при фокусе окна Mapper и `GetCursorPos`.

**US-18 Трей и выход (M).** Как игрок, я хочу закрыть окно и оставить хоткеи, чтобы окно не
мешало.
- Крестик прячет в трей; в трее «Открыть» и «Выход»; выход и кнопкой в окне.
- Выход во время замера сначала закрывает оверлей по правилам US-3.
- Вторая копия показывает окно первой (named mutex + named event).

### Распространение и разработка

**US-19 README и безопасная установка (M).** Как новичок, я хочу понять риск и проверить файл,
чтобы ставить без опасений.
- README RU/EN: GIF, оговорка о риске вверху, «Почему это не чит», «Делает / Не делает»,
  установка, хоткеи, FAQ, RAM, 10 импортов baseline (почему в exe есть `SendInput`).
- «Не для турниров; в Ranked на ваше усмотрение», «not affiliated with KRAFTON»; без слов safe,
  undetected, undetectable (CI) и без ассетов игры.
- Релиз: NSIS и portable exe, SHA256, attestations, команда проверки, шаги для SmartScreen.
- Установка без UAC; FAQ: при игре от администратора хоткеи не сработают.

**US-20 Проверки для контрибьютора (M).** Как контрибьютор, я хочу, чтобы CI ловил нарушения,
чтобы не сломать правила случайно.
- PR: `cargo test`, `clippy -D warnings`, `cargo deny`, vitest (`src/lib/core` ≥ 80%),
  `svelte-check`, guard; любой провал блокирует merge.
- Guard называет правило, файл и строку; исключения — только baseline с `# audited:` и README.
- Тег: guard проверяет импорты exe и собственного объектного файла Mapper.
- CONTRIBUTING, SECURITY, CHANGELOG, шаблоны issue (разрешение, DPI, версия).

## 5. Соответствие C-1…C-9

| Правило | Истории | Как соблюдено | Проверка |
|---|---|---|---|
| C-1 свой процесс | US-3, US-8, US-10 | Окна `Mapper.Overlay` / `Hud` / `Main`; в игре ничего не рисуется | guard: `LoadLibrary`, `GetProcAddress`, запуск процессов |
| C-2 не читаем игру | US-3, US-9 | Mapper не знает, запущена ли игра; прежнее окно — `ForeignHwnd`, только `restore()`, один раз | guard: имена и файлы игры, `GetWindow` |
| C-3 не смотрим экран | US-2, US-4 | Точки и калибровка — только клики | guard, deny.toml (31 крейт), Permissions-Policy |
| C-4 не шлём ввод | US-3, US-9, US-18 | `SetForegroundWindow` напрямую, без tao `set_focus`/fullscreen | guard + baseline; S-1: 0 утечек |
| C-5 только точки и константы | US-5…US-7, US-13 | Клики, сетка, формула, скорости из настроек; без действия игрока ничего не появляется | тесты core |
| C-6 только `RegisterHotKey` | US-11, US-18 | Свой поток; `device_event_filter(Always)`; при старте 0 raw-input устройств, иначе отказ | guard: обязательная строка, запрет хуков |
| C-7 честность | US-1, US-17, US-19 | Один текст риска в мастере, «О программе», README | CI: запрещённые слова |
| C-8 без админа | US-15, US-19 | `asInvoker`, `uiAccess=false`, всё для текущего пользователя | guard: манифест exe |
| C-9 не прячемся | US-17, US-19, US-20 | Постоянные классы, version resource, без UPX, сборка только в CI | guard по exe, attestations |

**Почему спавны, секретные комнаты и лут вне рамок.** Игра их не показывает, а вывод такой
информации Dev Letter 2026-06-25 прямо называет нарушением; это против C-5. Кроме того, нужны
были бы данные и изображения каждой карты (ассеты игры запрещены) и выбор карты, которого в
универсальной линейке нет. Автор отказался 2026-10-20 из-за риска бана, в любом окне.

## 6. Нефункциональные требования

| Область | Требование |
|---|---|
| Производительность | Цели раздела 3; вне замера hide + WebView2 `SetIsVisible(false)` + `MemoryUsageTargetLevel` LOW, пустой кадр перед скрытием, один процесс рендера |
| Экраны | DPI 100–200%; 1080p–4K, ultrawide, вертикальный; смешанный DPI (S-4: ошибка клика ≤ 1 px); оверлей = монитор − 1 px |

| Приватность | Без телеметрии и аккаунтов; сеть — только выключаемая проверка обновлений |
| Безопасность | Строгая CSP, `freezePrototype`, `withGlobalTauri:false`, ACL по окнам, отказ на permission request WebView2, лимиты в `show_hud`/`log_line` |
| Наблюдаемость | Локальный журнал с лимитом, без данных ввода; версия в «О программе» |

## 7. Вне рамок и v1.1

| Не делаем | Причина |
|---|---|
| Спавны, секретные комнаты, лут | Риск бана (раздел 5) |

| История замеров | Нужен только последний |
| Exclusive fullscreen, консоли, Mobile | Topmost-окно не видно; другие платформы |
| Второй экран, телефон | Позже отдельной функцией |
| Аккаунты, сервер, телеметрия, MSI | Приватность; хватает NSIS + portable |

## 8. План выпуска

1. Реализация; CI зелёный на каждом PR.
2. Проверки на аккаунте автора, в Training Mode, только релизной сборкой: S-4, S-2 (вспышки на
   видео), S-3 (PresentMon), G-1, G-2 (≥ 70% попаданий первым снарядом с Δh из ≥ 10),
   G-5/G-6 (с Discord и NVIDIA), `Alt+W` (О-3), по возможности U-3.
3. Замена `OWNER/mapper`, `v1.0.0-rc.1` как pre-release, тест с 2–3 новичками.
4. `v1.0.0`: установщик, portable, SHA256, attestations, guard по exe.
5. Через 90 дней — сверка метрик, объём v1.1. Откат — версия-исправление и пометка плохого
   релиза как pre-release.
