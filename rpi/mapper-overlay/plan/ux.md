## 0. Пользовательские истории и критерии приёмки

| ID | История | Критерии приёмки |
|---|---|---|
| US-1 | Как новичок с GitHub, я хочу пройти настройку без README | Мастер из 4 шагов; после шага 4 оба масштаба готовы или явно отложены; на каждом шаге есть следующее действие и способ проверить результат |
| US-2 | Как миномётчик, я хочу узнать дистанцию за 2 клика | От нажатия Alt+Q до числа на экране ≤ 3 с; число видно уже при наведении (до второго клика); рядом всегда «± N м» |
| US-3 | Как игрок, я хочу длину маршрута и время в пути | Длина каждого отрезка у линии, итог у последней точки и в панели; время бегом и на Dacia со знаком «≈» и скоростью |
| US-4 | Как миномётчик, я хочу поправку на высоту | Колесо меняет ΔH на ±1 м, Shift — на ±10 м; вне 121–700 м или без решения — предупреждение текстом и значком, без числа |
| US-5 | Как игрок, я не хочу перепутать зум | Режим назван словом и значком в панели и в HUD; видна сетка текущего масштаба; другой хоткей переключает режим и пересчитывает те же точки |
| US-6 | Как осторожный игрок, я хочу честно знать риск | Шаг 2 мастера и «О программе» содержат одинаковый текст риска; без слов «безопасно», «не обнаруживается»; продолжить можно только после отметки «понимаю» |
| US-7 | Как игрок, я хочу понять, почему не работает | Для занятого хоткея, нового монитора и потери фокуса — сообщение в момент проблемы; для того, что Mapper не может проверить (режим экрана, права администратора), — раздел «Если что-то не так» с самопроверкой |
| US-8 | Как пользователь клавиатуры и экранного диктора, я хочу управлять главным окном без мыши | Весь функционал главного окна доступен с клавиатуры, видимый фокус, подписи для Narrator, AA-контраст |

## 1. Принципы

1. **Линейка, а не прицел.** В интерфейсе, README и описании релиза нет слов aim, assist,
   auto, bot, radar и их русских аналогов («прицел», «помощник», «авто-», «бот», «радар»).
   Вместо «значение для прицела» — «дальность для миномёта», вместо «автозапуск» —
   «Запускать вместе с Windows», вместо «auto-hide» — «скрывается через 10 с». Ничего не
   появляется без действия игрока: оверлей — только по хоткею, HUD — только после замера с
   двумя и более точками, никаких предупреждений поверх игры при старте. Главное окно не бывает
   поверх всех окон.
2. **Скорость.** Первый замер за ≤ 3 с: хоткей → оверлей (замерено 26 мс до кадра) → клик →
   клик. Ничего не надо подтверждать, у появления оверлея нет анимации, расстояние до курсора
   видно ещё до второго клика.
3. **Читаемость поверх любой карты.** Жёлтая линия `#F2A900` с тёмным ореолом, цифры моноширинные,
   плотность стекла панелей ограничена снизу так, чтобы текст проходил WCAG AA даже над белым
   пикселем (раздел 2.2).
4. **«Жидкое стекло» + акцент `#F2A900`.** Настоящее размытие Windows (Mica/Acrylic) — только в
   главном окне и в HUD. Панели оверлея — стекло по виду (тон, блик, тень) без размытия:
   за прозрачным окном нечего размывать.
5. **Честность вместо проверок, которых нет.** Mapper не видит игру, поэтому не утверждает то,
   чего не знает («PUBG в эксклюзивном режиме»), а подсказывает: «если видишь X — сделай Y».
6. **RU/EN.** Язык по умолчанию — по языку Windows (ru-* → русский, иначе английский),
   переключается без перезапуска во всех окнах и в трее. Обращение на «ты» (как в спайке);
   в EN — нейтральное «you».

## 2. Дизайн-токены

Одна тёмная тема: игра тёмная, светлое окно при Alt+Tab слепит, а жёлтый акцент лучше читается
на тёмном. Светлой темы нет. Все размеры в CSS px (WebView2 сам умножает на масштаб Windows).

### 2.1 Цвета

| Токен | Значение | Где |
|---|---|---|
| `--bg-solid` | `#111316` | фон главного окна без эффектов (Windows 10 без Mica, выключены «Эффекты прозрачности»), forced colors — системные |
| `--bg-tint` | `rgba(17,19,22,0.55)` | тон поверх Mica в главном окне |
| `--glass-1` / `--glass-2` | `rgba(255,255,255,0.06)` / `0.09` | карточки / наведение и выбранный пункт навигации |
| `--glass-edge` | `rgba(255,255,255,0.10)` | рамка карточек |
| `--ov-panel` | `rgba(14,16,20,var(--ov-alpha))` | панели оверлея и тон HUD; `--ov-alpha` 0,78–0,94, по умолчанию 0,86 |
| `--ov-sheen` | градиент 160° `rgba(255,255,255,0.06)` → `0.02` к 45 % | блик стекла оверлея (в спайке 0,16 — снижен ради контраста) |
| `--text` | `#F3F1EA` | основной текст везде |
| `--text-2` | `#C9C5B8` | вторичный текст в оверлее и HUD (спайковый `#A7A395` не проходит AA над светлой картой) |
| `--text-3` | `#A7A395` | вторичный текст только в главном окне (на тёмном фоне) |
| `--accent` | `#F2A900` | линия, засечки, крупные цифры, фон основной кнопки |
| `--accent-text` | `#FFC53D` | мелкий жёлтый текст (метка режима, ссылки), фокус-кольцо |
| `--accent-ink` | `#1A1400` | текст на жёлтой кнопке |
| `--accent-soft` | `rgba(242,169,0,0.35)` | «резинка» от последней точки к курсору |
| `--halo` | `rgba(0,0,0,0.85)` | ореол линии и подписей на карте |
| `--ok` | `#6FD08C` | значок «готово» |
| `--warn` | `#FFB870` | предупреждения (текст и значок), в том числе в оверлее |
| `--danger` | `#FF7A7A` | ошибки, только в главном окне |

### 2.2 Контраст (WCAG AA)

Худший случай для оверлея — белый пиксель карты под панелью при минимальной плотности 0,78 и
блике 0,04: фон получается около `#4A4B4D` (яркость ≈ 0,07). Поэтому ползунок прозрачности не
опускает `--ov-alpha` ниже 0,78.

| Пара | Контраст | Норма |
|---|---|---|
| `--text` на худшем фоне оверлея | ≈ 7,8 : 1 | AA текст |
| `--text-2` на худшем фоне оверлея | ≈ 5,1 : 1 | AA текст |
| `--accent-text` на худшем фоне оверлея | ≈ 5,7 : 1 | AA текст |
| `--warn` на худшем фоне оверлея | ≈ 5,2 : 1 | AA текст |
| `--accent` на худшем фоне оверлея | ≈ 4,2 : 1 | только крупный текст ≥ 24 px или ≥ 19 px жирный (AA ≥ 3 : 1) |
| `--text-3` на `--bg-solid` | ≈ 7,4 : 1 | AA текст |
| `--accent-ink` на `--accent` | ≈ 8,7 : 1 | AA текст кнопки |
| Линия `--accent` 2,5 px с ореолом 1,5 px `--halo` | ≥ 3 : 1 к любому фону (через ореол) | AA графика (1.4.11) |

`--ok` в оверлее только в значке рядом со словом белым цветом; `--danger` в оверлее не используется.

### 2.3 Стекло, радиусы, тени

- Радиусы: `--r-xs` 6 (клавиши `<kbd>`, чипы), `--r-sm` 10 (кнопки, поля), `--r-md` 14 (карточки),
  `--r-lg` 18 (панели оверлея, HUD — как в спайке), `--r-pill` 999 (переключатели, бейджи).
- Блик: `inset 0 1px 0 rgba(255,255,255,0.30)` сверху и `inset 0 -1px 0 rgba(0,0,0,0.25)` снизу;
  рамка `1px rgba(255,255,255,0.18)` у панелей оверлея.
- Тени: панели оверлея и HUD `0 10px 32px rgba(0,0,0,0.40)`; карточки главного окна
  `0 4px 16px rgba(0,0,0,0.25)`; диалоги `0 16px 48px rgba(0,0,0,0.50)`.
- Главное окно: стандартная рамка Windows (без своего заголовка), тёмная тема окна, эффект Mica
  (Windows 11) или Acrylic (Windows 10), при недоступности — `--bg-solid`.
- HUD: Acrylic + тон `--ov-panel` той же плотности, что и панели оверлея.

### 2.4 Типографика

- `--font-ui`: `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif`;
  `--font-display`: `"Segoe UI Variable Display", "Segoe UI", sans-serif` для текста ≥ 20 px.
- `--font-num`: `"Cascadia Mono", Consolas, ui-monospace, monospace` + `font-variant-numeric:
  tabular-nums` для всех чисел (метры, время, пиксели, версии). Шрифты не встраиваются.
- Главное окно: заголовок мастера 28/34 Semibold; заголовок экрана 20/28 Semibold; заголовок
  карточки 16/22 Semibold; текст 14/20; подпись 12/16 (минимум, только `--text-3` и выше).
- Оверлей (минимум 13 px): метка режима 13/16 Bold, прописные, трекинг 0,14em; дистанция 30/34
  Bold `--accent`; значения 15/20; подсказки 13/18 `--text-2`; подписи на карте 14 px Semibold с
  ореолом 4 px (`paint-order: stroke`).
- HUD: дистанция 32/36 Bold `--accent` (как в спайке), строки 14/20 `--text-2` (в спайке 12).
- Числа: RU «1 240 м» (узкий неразрывный пробел U+202F), «6,3 м/с», «± 3 м»; EN «1,240 m»,
  «6.3 m/s». Время — `м:сс`, от часа — `ч:мм:сс`, всегда со знаком «≈».

### 2.5 Отступы и размеры

Шаг 4 px: 4, 8, 12, 16, 20, 24, 32, 48. Главное окно 900×640 (минимум), боковая панель 200,
поля контента 32, промежуток карточек 24. Кнопки: высота 32 (обычная), 36 (основная), цель
нажатия ≥ 24×24 (WCAG 2.5.8). Панель замера 360 шириной, отступ от края монитора 24.
Панель калибровки — по центру сверху, ширина 520. HUD 380×140.

### 2.6 Анимации

- `--dur-fast` 120 мс (наведение, нажатие), `--dur-base` 160 мс (смена шага мастера: сдвиг на 12 px
  + проявление; перенос панели замера в другой угол), `--dur-slow` 220 мс (проявление и угасание
  HUD). Кривая `cubic-bezier(.2,.8,.2,1)`.
- Без анимаций в простое: скрытые окна ничего не рисуют, нет бесконечных анимаций и спиннеров
  (вместо спиннера — текст «Проверяем…»). Показ и скрытие оверлея мгновенные (перед скрытием —
  пустой кадр, как в спайке).
- `prefers-reduced-motion: reduce` (WebView2 берёт его из настройки Windows «Эффекты анимации»):
  все длительности 0, сдвиги заменяются мгновенной сменой.

### 2.7 Фокус

`:focus-visible` — двойное кольцо: `outline: 2px solid var(--accent-text); outline-offset: 2px` и
`box-shadow: 0 0 0 4px rgba(0,0,0,0.6)` (кольцо видно и на стекле, и на светлом фоне). Фокус мышью
кольцо не рисует. В оверлее фокуса по Tab нет: окно целиком принимает клавиши (раздел 6.1).

## 3. Карта экранов и потоков

### 3.1 Карта

```
 Mapper.exe ──(первый запуск)──> МАСТЕР [1 Как работает] → [2 Риск] → [3 Режим экрана] → [4 Масштабы]
     │                                                                                   │
     │(уже настроен / мастер пройден)                                                   v
     v                                                                                ГЛАВНОЕ ОКНО
 ГЛАВНОЕ ОКНО ── Главная (статус, масштабы, последний замер, «Если что-то не так»)
     │           Настройки (хоткеи, язык, скорости, панели, монитор, система)
     │           О программе (версия, лицензия, ссылки, делает / не делает, риск)
     │  X / Alt+F4 → в трей (первый раз — диалог)      «Выйти из Mapper» / Ctrl+Q → выход
     v
 ТРЕЙ ── ЛКМ: открыть окно · ПКМ: меню (статус, Открыть, Доступна версия, Выход)

 В ИГРЕ (карта открыта):
 Alt+Q / Alt+W ──> ОВЕРЛЕЙ ──(масштаба нет для монитора / «Перенастроить» / C)──> КАЛИБРОВКА 1→4 ──Enter──┐
                      │  фокус не взят → «Кликни, чтобы начать» (3 с)                                     │
                      │<────────────────────────────── замер + подсказка «Проверка» <─────────────────────┘
                      │  другой хоткей → переключить режим (точки остаются)
                      └─ Esc / тот же хоткей (после отпускания всех клавиш) → игра + HUD на 10 с (если ≥ 2 точек)
```

### 3.2 Потоки

- **F-1. Установка и первый запуск.** Скачать установщик или portable exe → SmartScreen
  (инструкция в README, раздел 4.5) → открывается главное окно с мастером → шаги 1–3 → шаг 4:
  игрок идёт в Training Mode, приближает карту до упора, жмёт Alt+Q → оверлей сразу в
  калибровке → Enter → проверка «3 клетки = 300 м» → то же для Alt+W → «Готово» → Главная.
  Мастер можно закрыть крестиком (окно уходит в трей) — при следующем открытии он продолжится с
  того же шага; после «Готово» или «Настрою позже» больше не показывается (повторить —
  «Настройки → Пройти знакомство заново»).
- **F-2. Замер.** Alt+Q → оверлей с бледной сеткой → ЛКМ (точка 1) → у курсора живая длина →
  ЛКМ (точка 2) → в панели дистанция, «±», время, миномёт → Esc → игра, HUD на 10 с.
- **F-3. Маршрут.** Каждый следующий ЛКМ добавляет отрезок; длина отрезка у его середины, итог у
  последней точки и в панели; ПКМ или Backspace убирают последнюю точку, Delete — все.
- **F-4. Миномёт.** Ровно 2 точки: точка 1 — миномёт, точка 2 — цель. Колесо задаёт ΔH (цель
  выше — плюс). Панель показывает дальность для миномёта или предупреждение. При 3+ точках —
  «только для 2 точек».
- **F-5. Смена зума с переносом маршрута** (решение автора 2026-10-22, вместо переключения на
  месте). Во время замера другой хоткей (Alt+W при Alt+Q и наоборот) закрывает оверлей после
  отпускания клавиш и запоминает маршрут на 2 минуты; HUD: «Маршрут запомнен · Смени зум и нажми
  Alt+W · Затем кликни, где теперь первая точка». Игрок меняет зум в игре и жмёт этот хоткей:
  за курсором идёт «призрак» маршрута в новом масштабе, клик ставит первую точку, остальные
  пересчитываются по отношению двух масштабов (длина в метрах сохраняется), ΔH тоже. ПКМ,
  Backspace или Delete — начать заново. Тот же хоткей без смены зума возвращает точки на место
  (так исправляется нажатие не того хоткея). Если второго масштаба нет — сначала его калибровка,
  затем якорный клик. Mapper не видит карту, поэтому якорь ставит игрок — только его клики.
- **F-6. Выход и HUD.** Esc или тот же хоткей → оверлей ждёт отпускания всех клавиш (до 0,8 с,
  в Rust страховка 1 с) → фокус возвращается игре → HUD с итогом на 10 с, если было ≥ 2 точек.
  Новый хоткей сразу скрывает HUD.
- **F-7. Повторная настройка масштаба.** Три пути: (а) «Перенастроить» на Главной — режим
  «ждём хоткей», следующий Alt+Q открывает калибровку, а не замер; (б) C в замере;
  (в) Ctrl+колесо в замере — мелкая подгонка с сохранением.
- **F-8. Сброс масштаба.** «Сбросить» → диалог подтверждения (фокус на «Отмена») → карточка
  «Масштаб не настроен».
- **F-9. Новый монитор, разрешение или масштаб Windows.** Ключ калибровки — (монитор, размер
  оверлея в CSS px, масштаб). Нет записи для текущего ключа — Главная говорит «для 1920×1080 ·
  100 % не настроен», хоткей открывает калибровку с плашкой. Старая запись не удаляется и снова
  работает, если вернуть разрешение. Пересчёт пропорцией не делается: он не проверен.
- **F-10. Хоткей занят.** При старте `RegisterHotKey` вернул ошибку → окно открывается даже при
  запуске вместе с Windows, карточка с ошибкой → «Выбрать другое сочетание» → Настройки, запись
  хоткея в фокусе → проверка → сохранено. Другой хоткей продолжает работать.
- **F-11. Трей и выход.** X или Alt+F4 прячет окно в трей; первый раз — диалог «Mapper остаётся
  в трее». Выход: пункт трея «Выход», кнопка «Выйти из Mapper», Ctrl+Q в главном окне.
- **F-12. Новая версия.** Раз в сутки (если включено) запрос к GitHub Releases → баннер на
  Главной, пункт в трее, строка в «О программе». Ссылка открывает страницу релиза в браузере;
  Mapper ничего не скачивает.
- **F-13. Второй запуск.** Повторный запуск exe показывает уже открытую копию (named event),
  второе окно не появляется.
- **F-14. Запуск вместе с Windows.** Старт в трее без окна. Окно открывается только если хоткей
  не зарегистрировался.

## 4. Макеты

Тексты в макетах — реальные (RU). `( + )` — значок «готово» (галочка в круге), `( ! )` —
предупреждение (треугольник), `( . )` — ожидание (пустой круг), `(i)` — справка.

### 4.1 Главное окно (900×640)

**M-1. Мастер, шаг 1 — как это работает.** Боковой навигации в мастере нет.

```
+------------------------------------------------------------------------------------------+
| Mapper                                                                    -   [ ]   X    |
+------------------------------------------------------------------------------------------+
|  [=] Mapper                                        (1)-----(2)-----(3)-----(4)           |
|      for PUBG: BATTLEGROUNDS                       Как     Риск    Экран   Масштаб       |
|                                                                                          |
|   Линейка для карты PUBG                                                                 |
|   Два клика по карте — и ты знаешь расстояние, время в пути и дальность для миномёта.     |
|                                                                                          |
```

### 4.2 Оверлей

Весь монитор: лёгкая вуаль `rgba(0,0,0,0.06)` (видно, что замер идёт), курсор-перекрестие,
бледная сетка текущего масштаба (`--accent`, 1 px, 28 %), панель замера слева сверху. Если курсор
или точка подходит к панели ближе 32 px, панель переезжает в правый верхний угол (160 мс, при
reduced motion — сразу) и возвращается, когда место освободится. Панели не перехватывают клики
(кроме шага 1 калибровки).

Тексты «Если что-то не так» (раскрывающиеся `<details>` на Главной):

- **Нажимаю Alt+Q в игре — ничего не происходит.** Проверь значок в трее и статус хоткея выше.
  Нажми Alt+Q здесь, на рабочем столе. Если линейка открылась, а в игре — нет, скорее всего PUBG
  или Steam запущены от имени администратора: Windows не пропускает к обычной программе
  горячие клавиши из такого окна. Запусти Steam без прав администратора. Mapper сам права не
  повышает.
- **После Alt+Q линейки не видно, игра свернулась или мигнула.** PUBG в эксклюзивном
  полноэкранном режиме. Включи «Полноэкранный (в окне)»: Настройки → Графика → Режим экрана.
- **Сетка не совпадает с картой.** Карта прокручена до упора? Тот ли хоткей: Alt+Q — приближено,
  Alt+W — отдалено. Менял разрешение игры или масштаб Windows — перенастрой. Мелкое расхождение
  подгоняется Ctrl+колесом прямо в замере.
- **Числа отличаются в 10 раз.** При настройке перепутаны клетки 1 км и 100 м. Нажми
  «Перенастроить» и выбери другие клетки.

### 6.1 Оверлей

| Ввод | Замер | Калибровка |
|---|---|---|
| ЛКМ | поставить точку | шаг 1: выбрать клетки (кнопки); шаг 2: начало; шаг 3: соседнее пересечение; шаг 4: перенести начало сетки |
| ПКМ / Backspace | убрать последнюю точку | шаг назад |
| Delete | убрать все точки | — |
| Колесо | ΔH ±1 м (от себя — цель выше) | шаг 4: клетка ±2 % |
| Shift+колесо | ΔH ±10 м | шаг 4: клетка ±0,2 % |
| Ctrl+колесо (Ctrl+Shift — тонко) | подогнать масштаб и сохранить | — |
| Средняя кнопка | перенести начало сетки | — |
| G | показать / скрыть сетку | — |
| C | настроить масштаб заново | — |
| 1 / 2 | — | клетки 1 км / 100 м (в любой момент) |
| Enter | — | сохранить (шаг 4) |
| H | все клавиши / свернуть | все клавиши / свернуть |
| Esc | выйти в игру | отменить; если масштаба нет — выйти |
| Тот же хоткей | выйти в игру | выйти в игру |
| Другой хоткей | выйти, запомнив маршрут для другого зума (F-5) | выйти без сохранения калибровки |

Выход всегда после отпускания всех клавиш. Масштабирование WebView2 по Ctrl+колесу и
Ctrl+плюс/минус в оверлее и HUD выключено. Повтор клавиш (`repeat`) игнорируется.

### 6.2 Мастер

- Tab-порядок: содержимое шага сверху вниз (на шаге 1 — выбор языка, на шаге 2 — флажок и
  ссылка, на шаге 4 — «Ничего не происходит?» и «Как совместить сетку») → «Назад» → «Настрою
  позже» → «Далее» / «Готово».
- Enter — «Далее», если фокус не на ссылке или флажке; Space — флажок; Alt+← — «Назад».
- Esc в мастере ничего не делает (это не диалог; закрыть — крестиком, окно уйдёт в трей).
- При смене шага фокус переходит на заголовок шага (`tabindex="-1"`).

### 6.3 Главное окно

- DOM и Tab: навигация (одна остановка, стрелки ↑/↓ между пунктами, Enter — открыть) →
  содержимое экрана в порядке чтения → «Выйти из Mapper» (визуально внизу боковой панели,
  в DOM — последним, чтобы Tab не попадал на выход раньше контента).
- Ctrl+1 / Ctrl+2 / Ctrl+3 — Главная / Настройки / О программе; Ctrl+Q — выйти; Alt+F4 и X —
  в трей; Ctrl+плюс / минус / 0 — масштаб интерфейса 80–200 %.
- Enter / Space — активировать; стрелки — радиогруппы, сегменты языка, ползунок (Shift — шаг 10);
  Esc — закрыть диалог, отменить запись хоткея, свернуть раскрытый `<details>`.

### 6.4 Запись хоткея

1. «Изменить» (Enter) → Mapper снимает регистрацию обоих хоткеев, поле «Нажми сочетание…»,
   диктор: «Нажми новое сочетание. Esc — отмена».
2. Первое нажатие не-модификатора фиксирует сочетание (`preventDefault` для всего, включая Alt).
3. Локальная проверка: допустимы Alt или Ctrl (с Shift или без) + буква, цифра, F1–F24, стрелки;
   F1–F24 можно и без модификаторов. Нельзя: Win-сочетания, Esc, Tab, Enter, Space, буква или
   цифра без Alt/Ctrl, Alt+Tab, Alt+F4, Alt+Space, Alt+Esc, Ctrl+Alt+Del, PrintScreen,
   сочетание второго режима.
4. Проверка занятости через `RegisterHotKey` → «свободно — сохранено» или «занято другой
   программой».
5. Esc или Tab отменяют запись (Tab ещё и переводит фокус — ловушки нет); хоткеи регистрируются
   обратно. «По умолчанию» возвращает Alt+Q / Alt+W.

## 7. Доступность

- **Контраст:** таблица 2.2; текст на стекле считается по худшему фону; жёлтый `#F2A900` для
  текста — только крупный; линия и подписи на карте — с ореолом.
- **Размер шрифта:** главное окно — текст 14, подпись не меньше 12; оверлей — не меньше 13;
  HUD — не меньше 14. Главное окно выдерживает масштаб 200 % (Ctrl+плюс) без горизонтальной
  прокрутки: карточки встают в столбец.
- **Не только цвет:** каждый статус — значок своей формы (галочка, пустой круг, треугольник) +
  слово; режим — слово + лупа «+» / «−»; ошибки полей — текст под полем; значок трея меняет
  форму.
- **Движение:** раздел 2.6; нет мигания чаще 3 раз в секунду; отсчёт «кликни, чтобы начать» —
  текстом.
- **Экранный диктор (главное окно):** семантика `nav`/`main`/`h1–h3`; `lang` меняется вместе с
  языком; переключатели — `role="switch"` с `aria-checked`; ползунок с `aria-valuetext="25 %"`;
  статусы хоткеев и калибровки — `role="status"` (вежливо), занятый хоткей — `role="alert"`;
  «Последний замер» — `aria-live="polite"`; числа с единицами получают `aria-label` словами
  («1240 метров, плюс-минус 2 метра»); кнопки с понятным контекстом («Изменить сочетание для
  замера при отдалении, сейчас Alt+W»); подсказки полей через `aria-describedby`.
- **Контрастные темы Windows** (`forced-colors: active`): главное окно отказывается от стекла и
  берёт системные цвета, рамки видимы; в оверлее у SVG линии и сетки `forced-color-adjust: none`
  (измерительная графика должна оставаться жёлтой с ореолом).
- **Клавиатура в оверлее:** всё, кроме постановки точки, доступно с клавиатуры; HUD не
  фокусируется и дублирует то, что Главная показывает в «Последнем замере».

## 9. Решения, принятые в этом документе

1. Одна тёмная тема; `--text-2` осветлён до `#C9C5B8`, блик снижен до 0,06, а плотность панелей
   оверлея и HUD ограничена 0,78–0,94 (ползунок 0–100 % = 0,94 → 0,78), чтобы AA выполнялся над
   белой картой.
2. HUD — слева сверху, там же, где панель замера (в спайке — по центру сверху, где компас игры).
   Проверить в игре; при конфликте с элементами HUD игры вернуть вариант спайка.
3. Панель замера уезжает в правый угол, когда к ней подходит курсор или точка.
4. Живая длина у курсора до второго клика; «всего» у последней точки маршрута.
5. Миномёт — только при 2 точках (1 — миномёт, 2 — цель); при ОТДАЛЕНО подсказка «точнее при
   приближении».
6. При смене режима точки сохраняются и пересчитываются (под оверлеем та же картинка карты).
7. Калибровка: шаг 1 кликабелен, ПКМ/Backspace — шаг назад, «шаг N из 4», предупреждение о
   10× по порогу 3 км видимой высоты (порог уточнить в игре), проверка «3 клетки» после Enter.
8. Флажок «понимаю риск» обязателен для продолжения мастера.
9. Запуск вместе с Windows — в трей без окна; окно открывается, только если хоткей занят.
10. ЛКМ по трею открывает окно, ПКМ — меню; первое закрытие — диалог «остаётся в трее».
11. Кнопка «Проверить сейчас» — ручной запрос по действию игрока сверх автоматического раза в
    сутки; после ошибки сети автоматическая попытка — не раньше чем через сутки.
12. На время записи хоткея оба хоткея снимаются с регистрации; одиночные клавиши — только F1–F24.
13. Стандартная рамка окна Windows вместо своего заголовка (проще для диктора и Snap).
14. Язык по умолчанию — по языку Windows; выбор языка на шаге 1 мастера.

**Сверить до релиза:** точное название режима экрана и путь в меню русского клиента PUBG
(«Полноэкранный (в окне)», «Настройки → Графика → Режим экрана»); пороги предупреждения о 10×
(G-1); положение HUD относительно интерфейса игры.
