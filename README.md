# Mapper

Линейка для карты PUBG: BATTLEGROUNDS. Два клика по карте — и ты знаешь расстояние, время в пути
бегом и на Dacia и дальность для миномёта.

Бесплатно, открытый код, лицензия MIT. Только Windows 10 и 11. Mapper не связан с KRAFTON.
[English](README.en.md)

## Честно о риске

Гарантии от бана нет — её не даёт ни одна сторонняя программа, и Mapper тоже. Mapper — отдельная
программа-линейка: он не внедряется в игру, не читает её память, файлы и процессы, не делает
снимков экрана и не нажимает клавиши за тебя. Все точки ставишь ты сам, а расчёт идёт по сетке
карты и публичным параметрам, поэтому технический риск низкий. Но правила PUBG запрещают
неразрешённые KRAFTON программы, которые дают нечестное преимущество, а официального разрешения
или списка разрешённых программ нет. Стоит ли этот риск того, решаешь ты. Не используй Mapper в
турнирах; в рейтинговых матчах — на твоё усмотрение.

## Что Mapper делает и чего не делает

| Делает | Не делает |
|---|---|
| показывает окно поверх игры только после твоего хоткея | не читает память, файлы и процессы игры |
| считает по точкам, которые ты поставил | не делает снимков экрана и не распознаёт карту |
| вне своих окон слушает только два своих хоткея (`RegisterHotKey`) | не нажимает клавиши и не двигает мышь за тебя |
| по хоткею запоминает, какое окно было впереди, и по Esc возвращает ему фокус | не ищет окно игры и не знает, запущена ли она |
| в момент хоткея узнаёт, где курсор, — чтобы открыть линейку на нужном мониторе | не просит прав администратора |
| раз в сутки проверяет новую версию на GitHub (можно выключить) | не собирает данные о тебе |

## Установка

1. Скачай со страницы [релизов](../../releases/latest) один из файлов:
   - `Mapper_<версия>_x64-setup.exe` — установщик. Ставится для текущего пользователя, без прав
     администратора; папку можно выбрать (по умолчанию `%LOCALAPPDATA%\Mapper`).
   - `Mapper_<версия>_x64_portable.exe` — portable: запускается из любой папки без установки.
2. Файлы не подписаны сертификатом, поэтому Windows SmartScreen может предупредить. Нажми
   «Подробнее» → «Выполнить в любом случае».
3. По желанию проверь файл. `Get-FileHash .\Mapper_<версия>_x64-setup.exe` в PowerShell должен
   показать то же SHA-256, что в описании релиза и в `SHA256SUMS.txt`. То, что файл собран в
   GitHub Actions из исходников этого репозитория, проверяет `gh attestation verify` — точная
   команда есть в описании каждого релиза.

Mapper показывает свои окна через WebView2. В Windows 10 и 11 он обычно уже есть; установщик
доставит его сам, если нет.

### Удаление

- **Установщик:** «Параметры» → «Приложения» → «Установленные приложения» → Mapper → «Удалить».
  Вместе с программой уходит и автозапуск. Галочка «Удалить данные приложения» стирает ещё
  настройки и калибровку — не ставь её, если собираешься вернуться.
- **Portable:** выключи в настройках «Запускать вместе с Windows», закрой Mapper (значок в трее →
  «Выход») и удали файл.

## Первый запуск

Мастер из четырёх шагов: как это работает и язык, риск, режим экрана, настройка двух линеек.

- В PUBG включи режим «Полноэкранный (в окне)»: Настройки → Графика → Режим экрана. В эксклюзивном
  полноэкранном режиме линейку не видно.
- Запускай Steam и PUBG как обычно, не от имени администратора, — иначе Windows не пропустит
  горячие клавиши к Mapper.
- Масштаб настраивается один раз для каждого монитора, удобнее всего в Training Mode: приблизь
  карту колесом до упора и нажми `Alt+Q` (клетки по 100 м), потом отдали до упора и нажми `Alt+W`
  (клетки по 1 км). Мастер покажет, где кликнуть.

## Как пользоваться

Открой карту и прокрути колесом до упора: приближена — `Alt+Q` (короткие и средние дистанции, до
~600 м), отдалена — `Alt+W` (дальние). Кликай точки маршрута. Esc возвращает в игру; итог ещё
10 секунд виден в маленькой панели.

| Клавиша | Что делает |
|---|---|
| ЛКМ | поставить точку |
| ПКМ или Backspace | убрать последнюю |
| Delete | убрать все точки |
| Колесо | высота цели ±1 м (Shift — ±10 м) |
| Ctrl+колесо | подогнать масштаб (Ctrl+Shift — тонко) |
| Средняя кнопка | перенести начало сетки |
| G | показать или скрыть сетку |
| C | настроить масштаб заново |
| H | все клавиши |
| Esc или тот же хоткей | вернуться в игру |
| другой хоткей | сменить зум: маршрут сохранится |

Хоткеи меняются в настройках. Буквы и цифры — только с Alt или Ctrl, F-клавиши можно и без них.

## Если что-то не так

- **Нажимаю `Alt+Q` в игре — ничего не происходит.** Нажми его на рабочем столе. Если линейка
  открылась там, а в игре нет, PUBG или Steam запущены от имени администратора: Windows не
  пропускает горячие клавиши из такого окна к обычной программе. Запусти их как обычно.
- **После хоткея линейки не видно, игра свернулась или мигнула.** PUBG в эксклюзивном полноэкранном
  режиме. Включи «Полноэкранный (в окне)».
- **Сетка не совпадает с картой.** Карта прокручена до упора? Тот ли хоткей: `Alt+Q` — приближено,
  `Alt+W` — отдалено. После смены разрешения игры или масштаба Windows настрой заново. Мелкое
  расхождение подгоняется Ctrl+колесом прямо в замере.
- **Числа отличаются в 10 раз.** При настройке перепутаны клетки 1 км и 100 м. Нажми
  «Перенастроить» и выбери другие клетки.
- **Оверлеи Discord и NVIDIA.** Совместную работу с ними проверяем перед версией 1.0. Если что-то
  мешает, напиши в [issues](../../issues).

## Где данные и что уходит в сеть

- Настройки и калибровка: `%APPDATA%\dev.mapper.app\config.json`. Журнал:
  `%LOCALAPPDATA%\dev.mapper.app\logs\mapper.log`. Обе папки открываются из «О программе».
- Единственный сетевой запрос — раз в сутки к GitHub Releases, напрямую. Данных о тебе в нём нет;
  как любой сайт, GitHub видит IP-адрес, версию Mapper и время проверки. Выключается в настройках.

## Почему в exe есть SendInput и другие такие функции

Окна Mapper сделаны на Tauri (Rust + WebView2). Его библиотеки (tao, muda, wry, softbuffer)
импортируют несколько функций Windows, которые выглядят подозрительно. Mapper их либо не
вызывает, либо вызывает только для своих окон. Каждая сборка проверяет, что список импортов не
изменился (`antiban/imports-baseline.txt`), а Win32-вызовы самого Mapper сверяются отдельно
(`antiban/own-imports.txt`).

| Функция | Откуда и зачем |
|---|---|
| `SendInput` | tao — только для `set_focus` и полноэкранного режима, muda — для стандартных пунктов меню «Копировать», «Вставить» и подобных. Mapper не использует ни то, ни другое: guard запрещает их в исходниках |
| `SetCursorPos` | tao `set_cursor_position`; запрещено в исходниках и в правах окон |
| `ClipCursor` | tao `set_cursor_grab`; запрещено в исходниках и в правах окон |
| `RegisterRawInputDevices` | цикл событий tao; Mapper ставит `DeviceEventFilter::Always`, и tao снимает регистрацию (`RIDEV_REMOVE`) |
| `GetRawInputData` | обработчик `WM_INPUT` в tao; после снятия регистрации такие сообщения не приходят |
| `GetAsyncKeyState` | tao один раз читает состояние клавиш, когда окно Mapper получает фокус; без опроса |
| `GetKeyboardState` | tao читает состояние клавиш своей очереди сообщений, разбирая нажатия в окнах Mapper |
| `GetCursorPos` | один раз на нажатие хоткея — выбрать монитор, на котором открыть линейку |
| `FindWindowExW` | tauri-runtime-wry ищет своё дочернее окно внутри окна Mapper |
| `BitBlt` | softbuffer копирует свой буфер пикселей в своё окно — это рисование, не снимок |
| `GetDIBits` | tauri переводит иконку Mapper в RGBA |

## Как это проверяется

- **guard** (`npm run guard:all`) перед каждой сборкой проверяет исходники, права окон, собранные
  страницы, Win32-вызовы самого Mapper и импорты exe, а его собственные тесты подкладывают
  сотню нарушений и ждут, что каждое будет поймано. Это сетка правил, а не доказательство:
  главное — открытый код и ревью.
- Релизы собираются только в GitHub Actions; к файлам прикладываются SHA-256 и attestations.

Сборка из исходников и как добавить правило — в [CONTRIBUTING.md](CONTRIBUTING.md). Уязвимости —
по [SECURITY.md](SECURITY.md).
