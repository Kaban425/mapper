### Добавлено · Added

- Линейка поверх карты PUBG: `Alt+Q` — карта приближена, `Alt+W` — отдалена · A ruler over the
  PUBG map: `Alt+Q` zoomed in, `Alt+W` zoomed out.
- Расстояние, время бегом и на Dacia, дальность для миномёта с высотой цели · Distance, time on
  foot and by Dacia, mortar range with the target height.
- Настройка масштаба для каждого монитора и зума; маршрут переносится между зумами · Scale set per
  monitor and zoom; the route carries over between zooms.
- Маленькая панель с итогом на 10 секунд после замера · A small result panel for 10 seconds after
  a measurement.
- Главное окно: мастер первого запуска, «Главная», «Настройки» (хоткеи, язык RU/EN, скорости,
  прозрачность панелей, монитор, автозапуск), «О программе» · Main window: first-run wizard, Home,
  Settings (hotkeys, RU/EN, speeds, panel transparency, monitor, start with Windows), About.
- Проверка новой версии раз в сутки, выключается в настройках · A once-a-day check for a new
  version that can be turned off.
- Установщик для текущего пользователя без прав администратора и portable-версия · An installer
  for the current user without administrator rights, and a portable exe.
