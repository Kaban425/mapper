# Спайк Mapper: оверлей, хоткеи, фокус, универсальная линейка

Одноразовый прототип для проверки рискованных мест Mapper. Это не приложение: миномёта и
настроек нет, интерфейс — черновик в стиле «жидкое стекло».
Итоги — в [`rpi/mapper-overlay/research/SPIKES.md`](../../rpi/mapper-overlay/research/SPIKES.md).

## Запуск

Двойной клик по **`dist/Запуск Mapper.cmd`**. Окон не появится: приложение сидит в трее
(иконка — жёлтая линейка, может прятаться под «^»). Закрыть: трей → «Выход».

## Универсальная линейка

Все карты рейтинга (Erangel, Miramar, Taego, Rondo) — 8×8 км, поэтому при одинаковом зуме
масштаб одинаковый. Mapper использует два зума, которые всегда одинаковые, — «до упора»:

| Хоткей | Зум карты | Для чего |
|---|---|---|
| **Alt+Q** | приближена до упора (колесо вперёд до конца) | близкие и средние дистанции |
| **Alt+W** | отдалена до упора (вся карта на экране) | дальние дистанции |

У каждого хоткея свой масштаб, настраивается **один раз**. Нажал не тот хоткей во время
замера — режим переключится, повторное нажатие того же хоткея закрывает замер.

**Настройка масштаба** (откроется сама при первом нажатии хоткея; потом — клавиша **C**):

1. Выбери, какие клетки совмещаешь: **1** — большие (1 км), **2** — маленькие (100 м).
   При приближении до упора обычно видна сетка 100 м, при отдалении — 1 км.
2. Кликни на **пересечение** линий сетки.
3. Кликни на **соседнее** пересечение, через одну клетку вправо или вниз.
4. Колесом (Shift — тонко) подгони жёлтую пунктирную сетку, чтобы совпали **дальние** линии.
5. **Enter**.

В замере: ЛКМ — точка, ПКМ — убрать последнюю, колесо — ΔH (Shift ×10), Ctrl+колесо —
подогнать сетку, средняя кнопка — перенести начало сетки, T — сетка 1 км ↔ 100 м,
G — сетка вкл/выкл, Esc — выйти. В панели: дистанция «± N м», время бегом и на Dacia,
масштаб и **сколько метров помещается на экране**.

## Чеклист U-1…U-3 (Training Mode или обычный матч рейтинга/нормала на карте 8×8)

Training Mode — карта 2×2 км, на ней масштаб будет другим, чем на картах 8×8. Для U-1 и U-2
нужны карты 8×8 (подойдёт любой режим, где ты попадаешь на Erangel, Miramar, Taego или Rondo).

- **U-1. Одинаковый ли масштаб на всех картах.** На первой карте настрой оба масштаба
  (Alt+Q на приближении до упора, Alt+W на отдалении до упора). На следующей карте 8×8
  открой карту, зум до упора, нажми тот же хоткей: **бледная сетка Mapper должна лечь на
  сетку карты без подгонки**. Если сдвинута по фазе — средняя кнопка на пересечение;
  важно, совпадает ли **размер** клеток. Запиши: совпало / на сколько разошлось.
- **U-2. Сколько видно при приближении до упора.** Строка «Экран» в панели (Alt+Q):
  например «1 357 м × 763 м». Помещаются ли 600 м — понятно сразу.
- **U-3. Скорость Dacia без Shift.** Засеки время проезда 1 км по прямой (между двумя
  линиями большой сетки) на полном газу без ускорения. Пришли секунды — подставлю в расчёт.
  Сейчас в панели стоит заглушка 120 км/ч с пометкой «не проверено».

Если что-то странно — трей → «Открыть папку лога»: в логе каждая настройка масштаба с
точными числами (`calibrated near/far: ... m/px`).

## Сборка (для разработчика)

```powershell
$env:CARGO_TARGET_DIR = "$env:LOCALAPPDATA\mapper-target"
cd src-tauri
cargo test
cargo build --release
cargo deny check bans
cd ..
node scripts/antiban-guard.mjs --exe auto
```

Флаги exe: `--hotkey-near=Alt+Q`, `--hotkey-far=Alt+W`, `--mode=hide|cloak|always`,
`--low-memory`, `--renderer-limit`, `--cycle=100 --exit-after-cycle` (автотест S-2).
