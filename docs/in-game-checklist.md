# Чеклист проверки в игре

Проходит автор на **релизной сборке** (установщик или portable из черновика релиза, не локальная
сборка), своим аккаунтом: Training Mode и обычные матчи на картах 8×8. Результат с датой и
версией — в последнюю колонку. Технические замеры (CPU, RAM, PresentMon) — по `docs/perf.md`.

PUBG — в режиме «Полноэкранный (в окне)», Steam и PUBG запущены как обычно, не от имени
администратора.

## Перед релизом

| ID | Что проверить | Как | Пройдено, если | Результат |
|---|---|---|---|---|
| Лобби | Mapper не вызывает предупреждений | запустить Mapper до игры, зайти в лобби и в матч | никаких сообщений от игры или античита | спайк 2026-10-20: да |
| S-1 | фокус и ввод | в Training Mode 50 раз открыть линейку (`Alt+Q`, `Alt+W` вперемешку) поверх карты, ставить точки, крутить колесо, жать клавиши | линейка открывается каждый раз; карта игры не реагирует на клики, колесо и клавиши под линейкой; после Esc фокус у игры | спайк 2026-10-20: 105/105 |
| О-3 | Alt не залипает | после `Alt+Q` и `Alt+W` вернуться в игру и бежать, стрелять, открыть инвентарь | игра не считает Alt зажатым, обзор не включается сам | |
| S-2 | нет вспышки и старого кадра | записать видео 60 к/с: 20 открытий и закрытий линейки | ни одного кадра со старым замером, белого или чёрного прямоугольника | |
| S-4 | несколько мониторов | вертикальный монитор и мониторы с разным масштабом Windows: настроить масштаб на каждом и измерить 3 клетки | ошибка клика ≤ 1 px, 3 клетки = 300 м ± 2 м | |
| G-1 | шаг сетки | на каждом зуме сравнить сетку Mapper с сеткой карты у дальнего края экрана | линии совпадают без подгонки; если нет — записать, на сколько | |
| U-1 | один масштаб на разных картах | одна калибровка, замер на нескольких картах 8×8 | совпадает без подгонки | 2026-10-20: да |
| U-2 | дальность приближенного зума | приблизить до упора | на экране помещается ≥ 600 м | 2026-10-20: да |
| U-3 | скорость Dacia | проехать по ровной дороге отмеренный отрезок (≥ 500 м) без ускорения, засечь время, 3 раза | среднее записать; если оно отличается от 100 км/ч больше чем на 10 %, поменять значение по умолчанию | |
| G-2 | миномёт с высотой | ≥ 10 выстрелов по дальности из Mapper с учётом высоты цели | ≥ 70 % попаданий первым снарядом; иначе высота — экспериментальная функция | |
| G-5 | оверлеи Discord и NVIDIA | включить оверлеи Discord и NVIDIA (GeForce Experience / NVIDIA App), открыть линейку | линейка видна и работает, оверлеи не мигают и не перехватывают клики | |
| Точность | контрольные замеры | на обоих мониторах и зумах измерить известные расстояния (клетки) | расхождение ≤ 1 % | |
| DPI | масштаб Windows | 100 %, 125 %, 150 %, 200 %: перенастроить и измерить | Mapper сам предлагает перенастроить; после этого 3 клетки = 300 м ± 2 м | |
| Установка | установщик и удаление | поставить, запустить, включить автозапуск, удалить через «Параметры → Приложения» | ни автозапуска, ни папки программы после удаления | 0.1.0 локально, 2026-11-01: да |

## Если что-то не прошло

Записать в issue (шаблон «Ошибка» или «Масштаб не совпадает») с версией, монитором и журналом
(`%LOCALAPPDATA%\dev.mapper.app\logs\mapper.log`). Пункт, который нельзя исправить до релиза,
отмечается в README в «Если что-то не так».
